# Game compatibility patches

Standalone compatibility patches maintained in the NickGuAI/reastuff fork.
They are independent of the REA CLI and MCP packages.

| Patch | Description | License |
| --- | --- | --- |
| [Sengoku Rance for CrossOver](sengoku-rance-crossover/README.md) | Simplified Chinese glyph clipping/width correction and a 170% window scale | MIT |

Sources are tracked here. Compiled downloads are attached to tagged GitHub
releases; the packages contain no game executables, game assets, or fonts.
